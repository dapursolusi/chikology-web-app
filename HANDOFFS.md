### Decisions

- **D-020** — `getEbookLive()` returns `false` on any error (table missing, DB unavailable, malformed row). Safe-default-on-error: hiding the e-book is the correct posture during incidents. Tradeoff: a true `ebook_live = 'true'` row will be silently ignored if the query throws; alert by monitoring server error logs, not by user-visible behavior.
- **D-021** — Countdown component owns its own "released" fallback ("Sudah rilis" when `now >= 2026-06-16 00:00 WIB`), independent of the `ebook_live` flag. Defensive layering: if the pg_cron job that flips the flag fails, the timer still won't render negative numbers. The flag is the authoritative gate for nav/sidebar; the countdown's fallback is purely cosmetic.
- **D-022** — Disabled nav item uses `title` HTML attribute for tooltip, not shadcn `Tooltip` portal. Why: the disabled state needs to be testable in jsdom; shadcn `Tooltip` portal-mounts content only on `open`, which is hard to trigger reliably in unit tests. `title` attribute is universally testable via `toHaveAttribute('title', ...)`. Still works for sighted users (browser-native hover tooltip) and screen readers (via `aria-disabled`).
- **D-023** — `drizzle-kit push` does NOT run `INSERT` statements appended to migration SQL files. The seed line in `0001_naive_boomerang.sql` is documentation / `drizzle-kit migrate` path only. Seed was applied manually via `bun -e` one-off script. Going forward: either switch to `drizzle-kit migrate` for the seed-and-schema combo, or accept manual seed steps and document each in the relevant handoff.
- **D-024** — `src/components/app-sidebar-links.test.tsx` is now stale: it tests a literal copy of the old `navMain` array, not the actual sidebar config (which now depends on `ebookLive`). It still passes (because it's testing its own local literal), but it provides no real coverage. Left in place this session to avoid scope creep; flagged for deletion or replacement (see Known Issues).
- **D-025 (scope-drift, Hook B Phase-5)** — Final diff touched 14 files vs 10 planned. Extras: (1, 2) `drizzle/meta/0001_snapshot.json` + `drizzle/meta/_journal.json` — auto-generated by `drizzle-kit generate`, expected. (3) `src/test/setup.ts` matchMedia stub — necessary fix discovered during slice D execution; generic infra, helps all future shadcn-sidebar tests. All extras justified and necessary; not unintentional drift.
